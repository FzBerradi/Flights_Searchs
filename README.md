# Flights_Searchs

## Overview

**Flights_Searchs** is a web application designed to help users search for flights, view details about each flight,  with features that enable easy flight search and management.

## Features

- **Search Flights**: Users can search for available flights based on departure and destination cities, travel dates, and other filters.
- **Flight Details**: Users can view detailed information about flights such as prices, duration, and flight details.

## Technologies Used

- **Backend**: .NET 9
- **Frontend**: HTML, CSS, JavaScript .

## Installation

### Prerequisites
- .NET SDk 9

### Steps to Install

1. Clone the repository:
    ```bash
    git clone https://github.com/FzBerradi/Flights_Searchs.git
    ```

2. Navigate to the project directory:
    ```bash
    cd Flights_Searchs
    ```

3. Restore the NuGet packages:
    ```bash
    dotnet restore
    ```
5. Run the application:
    ```bash
    dotnet run
    ```

## Usage

- **Search for Flights**: Navigate to the home page and enter the desired departure and destination cities along with travel dates.
